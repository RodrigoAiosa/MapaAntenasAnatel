# Segurança

Este projeto não guarda dado pessoal nem tem login: é um site estático com a
base pública da Anatel. Encontrou uma falha (por exemplo, nos cabeçalhos em
`vercel.json` ou no código em `app/`)? Abra uma
[vulnerability report privada](../../security/advisories/new) no GitHub em vez
de uma issue pública.
